Course handbook

SDD with SPECTRA

Spec-driven development for engineers who already write code daily and have at least passing exposure to AI coding agents. You learn the method by running it — the core loop, a greenfield and a brownfield build, and the workflows that sit around it: deciding whether an idea is worth building, fixing what breaks, and shaping the process to fit your team. The labs run on SPECTRA; the method transfers to any Spec Kit project.

Total time About 13 hours
Pace Self-paced or 3-day workshop
Format 10 modules + 5 labs
SPECTRA and Spec Kit.SPECTRA is built on top of GitHub Spec Kit — it does not replace it. Spec Kit provides everything this course teaches as method: the spec-driven loop (constitution, specify, clarify, plan, checklist, tasks, analyze, implement, converge), the bug-fix and idea-assessment workflows, and the extensions, presets and overrides you customize it with. SPECTRA installs and keeps that toolchain current with one command, and adds its own agents for the work around the code — requirements, impact, architecture decisions, test strategy, root-cause analysis, and pull-request delivery. Everything except the speckit.spectra.* agents transfers to a plain Spec Kit project. SPECTRA is built and maintained by TELUS Digital — see the SPECTRA landing page for the full picture.
Command spelling.Every command has one identity — written speckit.specify or speckit.spectra.adr — and your coding agent decides how you type it. The course shows the form Claude Code and GitHub Copilot use: /speckit-specify, /speckit-spectra-adr. Other agents differ: kiro-cli uses /speckit.specify, Codex uses $speckit-specify, and Kimi uses /skill:speckit-specify. Your agent’s own command list always shows the exact trigger.

Suggested learning paths

Self-paced (recommended)
One or two modules per week over about six weeks. Gives the labs time to settle and the discussion prompts time to land in real team contexts.
Three-day workshop
Day 1: Modules 1–3 (foundations and the greenfield lab). Day 2: Modules 4–5 (the brownfield lab and idea assessment). Day 3: Modules 6–10 (bug fix, customization, practice, team, and AI-DLC).
Engineering-leadership track
Modules 1, 5, 8, 9, and 10 — read the concepts and skip the labs. Covers everything needed to sponsor adoption: the method, how ideas earn investment, what goes wrong, and how the lifecycle itself changes.
Hands-on track
The five labs — Modules 3, 4, 5, 6, and 7. For engineers who want to feel the practice before reading about it.

Lab codebase

Every lab uses the same kind of app — Next.js 15 + TypeScript + Tailwind CSS + localStorage, no backend — so what you learn in one lab transfers directly to the next. (The app you scaffold in Module 3 gets whatever create-next-app installs today, React 19 and Tailwind CSS v4; the Modules 4–7 starter pins React 18 and Tailwind CSS 3.)

  • Module 3 (greenfield) scaffolds a fresh Next.js project with create-next-app and uses SPECTRA to build a small to-do app from scratch.
  • Modules 4–7 use a starter codebase shipped with the course — a minimal but fully working to-do app with add, mark-done, and delete, and no specs. It mirrors the kind of codebase teams typically inherit. Module 4 adds a due date to it; Module 5 assesses ideas for it; Module 6 starts from a fresh copy to hunt down a real defect; Module 7 customizes the project you built in Module 4.

The starter ships as lab-codebase.zip; the download link is on each lab page. Unzip it and run npm install && npm run dev to get started.

Prerequisites

  • Working knowledge of JavaScript / TypeScript and React
  • Familiarity with the command line and Git
  • Access to an AI coding agent — Claude Code (recommended), GitHub Copilot, Cursor, or similar
  • Node.js 18.18+ for running the labs
  • uv and Git for installing SPECTRA (uv manages Python for you — you don’t write Python in any lab)
  • Spec Kit 1.0.9 or later. spectra install installs the latest release when Spec Kit is missing; spectra version shows what you have, and spectra update brings it current.
